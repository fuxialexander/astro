# Command Palette Quick Start Guide

## Opening the Palette

Press **`Cmd+K`** (Mac) or **`Ctrl+K`** (Windows/Linux) anywhere in the app to open the command palette.

## Basic Usage

### Search
- Start typing to fuzzy search across all commands
- Results are scored and highlighted
- Match quality shown as a colored bar on the left

### Navigate
- **↑ ↓**: Move between items
- **Enter**: Execute selected command
- **Esc**: Close palette (or go back if in nested view)

### Quick Actions
- Type "dashboard" → Navigate to Dashboard
- Type "new project" → Create new project
- Type "theme" → Toggle light/dark mode
- Type project name → Jump to that project

## Advanced Features

### Multi-Select Mode
1. Press **`Cmd+M`** to enable multi-select mode
2. **`Cmd+Click`** or **`Shift+Click`** to select multiple items
3. Batch operations appear in the footer
4. Press **`Cmd+M`** again to disable

### Recent Commands
- Your 5 most recent commands appear at the top
- Automatically sorted by recency and frequency
- Persisted across sessions

### Preview Panel
- Select any project to see details in the right panel
- Shows description, status, and metadata
- Updates in real-time as you navigate

### Clear Search
- Press **`Cmd+Backspace`** to clear the search input instantly

## Tips & Tricks

1. **Fuzzy Matching**: Don't need exact spelling - "envs" finds "Environments"
2. **Smart Ranking**: Frequently used commands rank higher
3. **Preview First**: Check project details before navigating
4. **Multi-Select**: Select multiple projects for batch operations
5. **Clear History**: Recent commands persist across sessions

## Troubleshooting

### Palette won't open
- Make sure you're using the correct modifier key (Cmd on Mac, Ctrl on Windows)
- Check if another app is capturing the shortcut

### Search not working
- Make sure you're typing at least 2 characters
- Try clearing the search with Cmd+Backspace

### Commands not appearing
- Check if the page has loaded fully
- Refresh the page and try again
