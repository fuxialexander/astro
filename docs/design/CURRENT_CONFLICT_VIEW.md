### 25. Session Bridge Tools: Server MCP vs. Agent Runner

- Total across both servers: **19 tools** (not 18)

**Resolution needed:** CLAUDE.md should distinguish between server-side MCP tools (15) and agent-runner MCP tools (4), rather than conflating them into a single "18 tools" count.
