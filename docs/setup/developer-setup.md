# Developer Setup

Getting started with Astro local development.

## Prerequisites

- Node.js 18+ (22.x recommended)
- npm or pnpm
- Git

## Quick Start

```bash
# Clone repository
git clone https://github.com/fuxialexander/astro
cd astro

# Install dependencies
npm install

# Start dev server (Local Mode - IndexedDB only)
npm run dev

# OR start dev server (Server Mode - with Supabase)
npm run dev:supabase
```
