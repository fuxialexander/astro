How It Works

Three Pillars

Structured planning, parallel execution, and human-in-the-loop decisions. All visible at once.

01

Plan

Not a todo list. A dependency graph. AI decomposes your goal into tasks with explicit dependencies. Parallel branches run simultaneously. Blocked tasks wait. You see the critical path at a glance.

02

Execute

Tasks dispatch across local machines, HPC clusters, and cloud. Each task gets a worktree. Results come back as PRs.

$astro dispatch task-3
detecting... git repo, github remote
worktree astro/task-3 created
provider claude-code
running 48 tool calls...
PR #142 ready for review

Approve

Astro amplifies human decision-making at the scale of complexity that once required entire teams.
