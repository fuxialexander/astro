Our Mission

We provide the planning and orchestration layer for long-horizon work—helping you structure complex goals, coordinate execution across environments, and surface the critical moments that require human judgment. Astro amplifies human decision-making at the scale of complexity that once required entire teams.

Get Started

One Command

Create an account, then register your machine with one command. No global install, no config files.

$ npx @astro/agent launch Copy

Requires Node.js 18+. Runs setup + connect in one step.

01
Detects your AI providers
Finds Claude SDK, Claude Code, or Codex on your machine automatically.
02
Discovers your SSH hosts
Reads ~/.ssh/config and offers to register remote machines (servers, HPC login nodes, cloud VMs).
03
Authenticates via device code
Opens a browser link. Approve the code and your machine is registered to your Astro account.
04
Connects and listens
Joins the relay network. Tasks dispatched from the Astro UI land on your machine in seconds.
Terminal

What You Get

Everything runs through astroanywhere.com. Your machines do the work. Astro handles the rest.

Plan
Describe a goal. Astro decomposes it into a dependency graph of tasks.
Execute
Dispatch tasks to any registered machine — laptop, server, or HPC cluster.
Monitor
Watch agent output stream live. See every tool call, file change, and decision.
Decide
Approve, reject, or redirect when agents surface decisions that need you.
Branch per Task
Every task runs on its own git branch. PRs are created automatically.
Multi-Machine
Tasks route to the best available machine by load and capability.

Self-hosted / local deployment is on the roadmap. Currently Astro runs as a hosted service at astroanywhere.com.
