## Prerequisites

- Node.js 20+ and npm/pnpm
- Git

## 1. Clone the Repository

```bash
git clone https://github.com/astro-anywhere/astro.git
cd astro
pnpm install
```

## 2. Start in Local Mode

Local mode uses PGlite (Postgres-in-WASM) — no Docker or external services required.

```bash
npm run dev:local
```

This starts:
- **Vite dev server** at [http://localhost:5173](http://localhost:5173)
- **Hono API server** at [http://localhost:3001](http://localhost:3001)
- **WebSocket relay** at [http://localhost:3002](http://localhost:3002)

## 3. Create Your First Project

1. Open [http://localhost:5173](http://localhost:5173) in your browser
2. Click **New Project**
3. Enter a goal description (e.g., "Build a task management web app with user authentication")
4. Click **Generate Plan** — Astro's AI will create a structured plan graph

## 4. Connect a Machine

To dispatch tasks to an agent, you need to connect at least one machine:

```bash
# Install the Astro CLI
npm install -g @astroanywhere/cli

# Register this machine
astro-cli machine register --url http://localhost:3001
```

## 5. Dispatch Your First Task

1. In the plan graph, click on any task node
2. Click **Dispatch** in the task panel
3. Watch the activity feed stream live output from the agent
