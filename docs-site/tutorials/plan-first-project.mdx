## Overview

This tutorial walks through the full Astro workflow from goal description to task execution.

## Prerequisites

- Astro running locally (`npm run dev:local`)
- At least one registered execution machine (or use local execution)

## Step 1: Create a New Project

1. Open Astro at [http://localhost:5173](http://localhost:5173)
2. Click **New Project** in the sidebar
3. Enter a name: *"My First API"*

## Step 2: Describe Your Goal

In the project description, write a clear goal statement:

```
Build a REST API for a simple task management app.
Stack: Node.js + TypeScript + Hono + SQLite.
Features: create/list/complete tasks, user authentication.
Timeline: 2 days.
```

The more context you provide — stack preferences, constraints, timeline — the better the generated plan.

## Step 3: Generate the Plan

Click **Generate Plan**. Astro will stream a structured plan as a directed graph. You'll see:

- **Milestones** as high-level groupings
- **Tasks** as leaf nodes with descriptions
- **Dependency edges** connecting tasks that must complete before others

## Step 4: Review and Refine

Review the generated plan. Common refinements:

- **Add a task** — Click the `+` button on any node
- **Edit a task** — Click the task title to open the edit panel
- **Reorder** — Drag nodes in the graph view
- **Delete a task** — Right-click → Delete (downstream tasks are unaffected unless you delete a dependency)

## Step 5: Dispatch Tasks

Click **Dispatch** on a ready task (all dependencies completed or no dependencies). The task sends to your registered execution machine.

<Tip>
  Tasks with no dependencies can all be dispatched immediately and run in parallel.
</Tip>

## Step 6: Review Results

When a task completes:
- **Auto-verified** (tests pass) → Task closes automatically
- **Awaiting judgment** → Appears in your review queue with a summary

Approve or request changes. Approved tasks mark their dependents as ready to dispatch.
