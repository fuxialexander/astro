## Installation

```bash
npm install -g @astroanywhere/cli
astro-cli --version
```

## Authentication

```bash
# Authenticate with your Astro server
astro-cli auth login --server https://api.astroanywhere.com

# For local development
astro-cli auth login --server http://localhost:3001
```

## Common Commands

### Projects

```bash
# List all projects
astro-cli projects list

# Create a new project
astro-cli projects create --name "My Project" --description "Goal description"

# Open a project
astro-cli projects open <project-id>
```

### Tasks

```bash
# List tasks in current project
astro-cli tasks list

# Show task details
astro-cli tasks show <task-id>

# Dispatch a task
astro-cli tasks dispatch <task-id>

# Cancel a running task
astro-cli tasks cancel <task-id>
```

### Machines

```bash
# List registered machines
astro-cli machines list

# Show machine status
astro-cli machines status
```

## TUI Mode

The CLI includes an interactive TUI (terminal user interface) for a richer experience:

```bash
astro-cli tui
```

The TUI provides a full-screen view of your projects, plans, and running tasks — useful for monitoring from a terminal or over SSH.
