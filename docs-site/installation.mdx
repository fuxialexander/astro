## System Requirements

| Requirement | Version |
|------------|---------|
| Node.js | 20+ |
| pnpm | 9+ |
| Git | 2.30+ |

For **Dev mode** (multi-user with auth):
- Docker Desktop or Docker Engine
- A Cloudflare account (for tunnel)

## Installation

### Clone & Install Dependencies

```bash
git clone https://github.com/astro-anywhere/astro.git
cd astro
pnpm install
```

### Environment Setup

Generate environment files:

```bash
npm run env:init
```

This creates `.env.local.dev` (for dev mode) and `.env.prod` (for production). See [Environment Variables](/setup/environment-variables) for all options.

## Operating Modes

Astro has three modes — choose the one that fits your workflow:

<Tabs>
  <Tab title="Local Mode">
    **Best for:** Individual development, rapid iteration, no external services.

    Uses PGlite (Postgres-in-WASM) embedded in the backend process. No authentication.

    ```bash
    npm run dev:local
    ```

    Available at: [http://localhost:5173](http://localhost:5173)
  </Tab>
  <Tab title="Dev Mode">
    **Best for:** Multi-user testing, WebAuthn/passkey auth, real-time collaboration.

    Requires Docker + Cloudflare tunnel. Enables full authentication and multi-user features.

    ```bash
    # Requires CLOUDFLARED_DOMAIN in .env
    npm run dev:dev
    ```
  </Tab>
  <Tab title="Production">
    **Best for:** Deploying for your team.

    Fly.io backend + Cloudflare Pages frontend + Remote Supabase.

    ```bash
    npm run deploy
    ```

    See [Production Deployment](/setup/production) for full instructions.
  </Tab>
</Tabs>

## Install the CLI

The Astro CLI lets you manage projects and machines from the terminal:

```bash
npm install -g @astroanywhere/cli

# Verify installation
astro-cli --version
```

See [CLI Overview](/cli/cli-overview) for all commands.

## Install the Agent Runner

The agent runner (`astro-agent`) executes tasks on registered machines:

```bash
npm install -g @astroanywhere/agent

# Verify installation
astro-agent --version
```

See [Agent Runner](/cli/agent-runner) for configuration.
