# Welcome to Astro

**Astro** is a planning-first platform for builders (software developers) and scientists (researchers). It provides an AI-assisted planning layer that sits above your execution tools — coding agents, analysis pipelines, and compute clusters — so you can focus your attention on the decisions that actually require a human brain.

<Info>
  Astro is currently in early access. [Join the waitlist](https://astroanywhere.com) to get started.
</Info>

## What Astro Does

Describe your goal — a product to ship or a research question to explore — and Astro generates a **structured plan as a directed graph**. You refine it. Agents execute tasks with dependency awareness, across any environment you control. You make the strategic decisions that matter.

## The Core Problem

Today's AI-assisted work is stuck in a **one-thing-at-a-time chat loop**:

- **Builders** describe features one at a time, manually injecting product context, with no coordination across agent sessions
- **Scientists** juggle branching analyses across scattered notebooks, Slurm logs, and local scripts — with no way to see the full exploration tree

Both groups need the same thing: a planning layer above their execution tools that handles goal decomposition, dependency management, parallel dispatch, and strategic decision-making.

---

## The Planning Loop

<Steps>
  <Step title="Describe your goal">
    Provide a product to build or a research question to explore. Include your background, timeline, and constraints. Astro's AI generates a domain-expert plan tailored to your context.
  </Step>
  <Step title="Refine the plan">
    Accept, modify, reorder, add branches, or prune entire lines of inquiry. The plan is a **directed graph** — not a flat list — supporting both linear pipelines and branching exploration trees.
  </Step>
  <Step title="Dispatch to agents">
    Tasks run automatically based on dependency order, across any environment you specify: local machine, HPC cluster (Slurm), or cloud. Parallel tasks run simultaneously.
  </Step>
  <Step title="Make the decisions that matter">
    Auto-verifiable tasks close on their own (tests pass, build succeeds, analysis completes). Your attention goes to **judgment calls** — does this feature match the vision? Is this result worth pursuing?
  </Step>
</Steps>
